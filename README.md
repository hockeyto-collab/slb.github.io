# 시니어라이프비즈니스 홈페이지

시니어트렌드 시리즈와 현장 리서치 매거진, 강의·교육·컨설팅을 소개하는 정적 홈페이지입니다.

GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시 소스로 사용합니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 최학희 소개, 전문 분야와 연구 콘텐츠 |
| `publication.html` | 연구, 시니어트렌드 시리즈와 관련 저서 |
| `magazine.html` | 마케팅·비즈니스·빈틈 1·2 매거진 |
| `education.html` | 교육 소개와 생활 질문·대전환 지도 |
| `lecture.html` | 강의 |
| `consulting.html` | 컨설팅 |
| `services.html` | 서비스 안내 |
| `contact.html` | 이메일 연락처와 주소 복사 |
| `about.html` | 기존 소개 링크를 홈으로 연결 |
| `style.css` | PC·모바일 공통 스타일 |
| `assets/` | 표지·인물·현장·교육자료 이미지 |
| `.nojekyll` | 빌드 없이 정적 파일 게시 |

내용 수정 시 해당 HTML 파일을 편집합니다. 이미지 변경 시 `src`와 `data-lightbox-src`를 함께 확인합니다. 문의 이메일은 `hockeyto@gmail.com`입니다. 별도 유료 서버나 문의 접수 서버는 사용하지 않습니다.

소개 문구는 사용자 제공 이력과 확인 내용을 바탕으로 작성했습니다. 경력 총 28년과 공공기관 신사업개발 교육 경험을 소개하며, 고객사·기관·매체의 실명이나 미확인 성과는 추가하지 않습니다. 연구 메뉴는 기존 `publication.html` 주소를 유지합니다. 블로그와 유튜브 SLB는 공통 하단에서 연결됩니다.

프로필에서는 여러 산업의 기업 실무, 법인·개인사업 창업과 비영리 활동을 경험의 맥락으로 소개합니다. 생활스포츠·공동주택 생활서비스·커뮤니티케어·공공부문 리서치 사례는 구체 기관명 없이 표시하며, 서로 중복될 수 있는 경력·사업체·단체의 수를 합산하지 않습니다.

교육 페이지에는 사용자 제공 14개 생활 질문·3개 스펙트럼 자료와 초고령사회 대전환 지도를 원본 해상도의 웹용 이미지로 제공합니다. 두 자료의 분류 관점을 구분하고 확대 열람을 지원합니다. 기존 라이프스타일 자료는 접을 수 있는 참고자료로 보존합니다.


## 디자인 수정

공통 디자인은 `institutional.css`, 홈의 실행 흐름 도표는 `diagrams.css`에서 관리합니다. `style.css`는 기존 레이아웃과 기능의 기본 스타일이며, 각 HTML에서 공통 테마를 뒤에 불러옵니다. 책 표지·교육 자료·명함의 확대 보기, 교보문고 구매 링크, 미디어 필터와 이메일 주소 복사 기능은 유지합니다.


연구·매거진의 주제와 수록 사례, 홈의 산업·역할별 경력은 `editorial-proof.css`로 표시합니다. 경력에는 주요 기업 근무·사업·공익 활동을 연도 구분 없이 소개합니다. 미국기업연구소(AEI) 인턴은 이전 경력의 한 줄로 표시합니다. 현재·이전 활동의 기관명은 굵게, 역할은 보통 글자로 구분합니다. 연도별 연혁과 공개용 프로필 PDF는 제공하지 않습니다. 원본 이력서와 지원·제안 문서도 게시하지 않습니다. 매거진에는 마케팅·비즈니스의 전체 목차(7개 장·4개 학습용 가상 사례와 읽는 법·설계 노트·서식·후속 항목 포함), 빈틈 01의 12개 주제별 비교 사례와 빈틈 02의 18개 사례를 표시합니다. 수록 사례명은 분석 대상이며 고객사 목록으로 사용하지 않습니다.



연구 페이지는 교보문고 e북 상품에 공개된 목차를 바탕으로 시니어트렌드 2027의 5부·14개 생활 질문·28개 마켓 신호와 신탁 저서의 3부·9장·세부 주제를 제공합니다. 인터뷰 직함은 책 수록 당시 기준입니다.

언론·기고 목록은 `media-data.json`과 `media.html`에서 관리합니다. 사용자 제공 기사 11건 중 기존 1건은 중복 추가하지 않고 신규 10건을 반영했습니다. 2023년 경남CBS 인터뷰를 포함해 발행일 기준 최신순 38건(날짜가 확인된 자료 37건·연도만 표시한 MC 프로그램 1건)으로 제공합니다. 기사 이미지가 확인되지 않은 경우 매체명 표지를 표시합니다.


컨설팅의 산출물 예시는 신사업·마케팅 전략, 영업·제휴·홍보 실행안, 운영매뉴얼, 수요예측, CRM 분석, 앱 기획을 공개용으로 새로 구성한 이미지이며 실제 고객 데이터나 원본 화면을 게시하지 않습니다. 고객·브랜드·지명·날짜·실제 수치와 원본 파일 정보가 포함되지 않도록 확인하며, 설명용 예시임을 페이지에 표시합니다. 이미지 경로와 확대 보기 경로는 함께 관리하고, 배치는 `consulting-examples.css`에서 조정합니다.

연구·리서치 매거진 페이지의 상단 표지 모음은 각 책의 상세 소개로 이동하는 링크입니다. 배치는 `book-overview.css`에서 관리합니다. 연구와 집필의 기록은 배경을 일러스트로 정리한 책 사진과 함께 기획·공저·감역·교육 교재 등 각 작업의 참여 역할을 구분해 표시합니다.

연구 페이지에는 블로그와 유튜브의 공개 첫 화면 일부를 연구 채널 카드로 연결합니다. 캡처에 개인 세션 정보·조회수·구독자 수가 포함되지 않도록 검토하고, 캡처 이미지를 갱신해도 공식 채널 링크를 유지합니다.

컨설팅의 대표 프로젝트 카드는 시니어 제조·케어·여가·서비스, 시니어 공공·민간 기관 및 공공·민간 기관의 적용 분야와 주요 산출물을 구분해 소개합니다. 소개된 항목은 수행 범위의 일부이며, 이미지는 실제 고객 원본이나 검증된 성과를 의미하지 않는 공개용 재구성 예시입니다.

연구 페이지에는 『시니어 레거시』(공저)의 표지·공개 목차·교보문고 종이책/e북 구매 링크를 추가합니다. 시니어트렌드 2027, 신탁, 레거시의 세부 목차는 기본 닫힘 상태의 네이티브 접기·펼치기로 제공합니다. `research-toc-toggle.css`에서 표시를 관리합니다.

강연의 선별 현장 기록은 `lecture-gallery.css`로 관리합니다. 강의실·해외 포럼·전시 연계 북토크 사진은 공개용 비식별 편집본만 게시하고, 원본 사진·안내장은 게시하지 않습니다. 강연자의 역할이 확인된 사진만 얼굴을 남기고 다른 참석자의 얼굴과 기관·이름 표기를 가립니다. 해외 무대·청중은 한 행사 기록으로 묶으며 북토크를 기조강연으로 표현하지 않습니다.

교육의 `course-models.css`는 운영 경험에 기반한 신사업개발과정과 개설을 준비하는 신탁 트렌드 아카데미 설계안을 구분합니다. 기획안에 적힌 예시 강사를 확정 강사진으로 공개하지 않고, 전문영역을 연결하는 구조만 소개합니다.

리서치 매거진은 2026년 가을부터 이어지는 기록으로 소개합니다. 매일 약 300개 이슈를 살펴 사례를 엄선한다는 설명은 저자 제공 연구 방식이며, 이를 매거진·영상·책과 교육·강연·컨설팅으로 연결합니다.
